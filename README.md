# 2026-10-31 試遊版 v3

今回の更新（倒れ方・部位の欠損・出血と応急処置・敵の武器・AIの仲間）：

- 倒れ方：撃たれた瞬間に力が抜け、重い体が重力でどさっと崩れ落ちるようにしました（以前の、しばらく体を支えようとする動きはやめました）。関節の曲がる範囲は人の体に近い狭さで、床に倒れると摩擦で急速に止まります（倒れてから約1秒）。
- 部位の欠損（ショットガンの至近距離）：腕は当たった位置によって「肘から先」か「肩から」、頭部、脚がもげます。もげた部位は1つの重い物として短く飛び、空中を舞わずに床へ落ちて止まり、切り口から血が噴き出します。壁を貫通して弱まった散弾では欠損しません。設定「ショットガンによる頭・腕・脚の吹き飛び」は初期状態をオンにしました。
- 立てなくなった敵：脚を失った敵、または脚に3発当たった敵は、立てずに伏せたまま這い、見えれば撃ってきます。出血が続き、放っておくと失血死します（脚を失った場合は約30秒）。
- 敵の武器：突撃役はショットガン、ほかはライフル。ハンドガンは主力武器が使えないとき（弾を撃ち尽くした、または弾倉が空で相手が目の前にいる）だけ抜き、落ち着いたら主力武器に戻します。
- 敵の戦い方を慎重に：同時に詰めてくるのは2人まで。近づくほどしゃがんでゆっくり、遮蔽物の陰を通って詰めます（突撃役も）。撃たれて体力が減ると早めに遮蔽物へ下がります。無線・回り込み・遮蔽物の選び方などの知能はそのままです。
- 自分の出血と応急処置（体力は回復しません）：被弾した場所によって、軽い出血、手足の激しい出血、胴体の激しい出血が起き、体力が減り続けます。H キーでいちばん危ない傷から処置します（止血帯：手足の激しい出血、止血剤：胴体の激しい出血、包帯：軽い出血。合う道具がなければ包帯で押さえるだけで、完全には止まりません）。処置中（2.5〜4秒）は銃を下ろしていて撃てず、もう一度 H で中断。救急箱は体力を戻すものではなく、医療品の補給になりました。
- 出撃前の装備「医療ポーチ」：止血帯・止血剤・包帯を、合計6個まで選んで持っていけます。
- 自分の負傷：脚に3発当たると立てなくなり、這って移動しかできません（撃つ・処置はできます）。敵のショットガンを至近距離で受けると、脚や片腕を失うことがあり、頭なら即死です。脚を失うと切り口から激しく出血するので、止血帯で止めないと失血死します。片腕を失うと、両手で構える主力武器は狙いが大きくぶれ、反動も抑えられず、照準も装填も遅くなります（ハンドガンは比較的扱えます）。脚に傷があると歩きが遅く、腕に傷があると狙いがぶれます。
- 手りゅう弾：爆風で近くの木の壁に穴が開き（近いほど大きい）、木箱が壊れます（背の高い箱は上の段が飛び、低い箱は砕けます）。壊れた分は弾・視線・当たり判定・敵の移動にも反映され、やり直すと元に戻ります。仲間も爆風に巻き込まれます。
- AIの仲間（2人）：設定「AIの仲間」で 2人／なし を選べます（初期は2人）。仲間は自分の少し後ろについてきて、敵が見えたら遮蔽物の陰から撃ちます。突っ込まず、撃たれて身をさらしていれば近くの遮蔽物へ移ります。自分が射線に入る位置では撃たずに横へずれますが、外れ弾は当たることがあります（誤射あり。自分の弾も仲間に当たります）。敵は仲間も狙います。仲間も出血し、脚に3発で這うだけになり、放っておけば失血死します。安全なときは自分で処置し、自分が仲間のそば（約1.8m以内）で H を押すと、自分の医療品で仲間を処置できます。F キーで「ついてこい／その場で待て」を切り替えます。左上に仲間の状態が出ます。協力プレイを入れるときも、この処置の仕組みで仲間を治療できるようにする予定です。

## 起動方法

1. ZIPを右クリックして「すべて展開」し、フォルダーごと解凍します（ZIPの中から直接開くと動きません）。
2. 解凍したフォルダーの中の `index.html` をダブルクリックし、Chrome か Edge で開きます。
3. 「出撃する」を押すと、マウスが画面に固定されてゲームが始まります。Esc で一時停止です。

ローカルサーバーは不要です。3D描画ライブラリ（Three.js r128）を `js/three.min.js` として同梱しているので、インターネットにつながっていなくても起動します。万一このファイルが無い場合だけ、インターネット上（cdnjs → jsDelivr の順）から読み込みます。

動作が重いときは、メニューの「設定」で画質を「軽量」にしてください（影を切り、照明を減らします）。画質は「高」「標準」（初期設定）「軽量」の3段階です。「フレームレートを画面右上に表示」をオンにすると、1秒あたりの描画回数を確認できます。60前後なら滑らかに動いています。

## 機能の詳細

### 操作
- リーン：視点の位置と射線を左右へ約0.42mずらし、画面を傾けます。壁際では壁の手前で止まり、カメラが壁に入り込みません。匍匐中は使えません。
- 姿勢：立ち（目線1.64m）・しゃがみ（1.08m）・匍匐（0.34m）。目線は短い補間で変わり、体の当たり判定の高さ（1.8／1.2／0.5m）も同時に変わります。頭上に障害物があるときは立ち上がれません。
- ダッシュ：開始時にリーンと照準を解除します。しゃがみ・匍匐中は押しても立ち上がりません。射撃ボタンを押すとダッシュは止まります。
- フォーカスを失ったとき（別ウィンドウへの切り替えなど）は、押しっぱなしの入力をすべて解除します。

### 射撃
- 弾は画面中央（カメラ）からまっすぐ飛ぶので、リーン・姿勢・スコープを使っても照準と着弾がずれません。腰だめ射撃は少しばらつき、移動中は大きくなります。
- 頭は球、胴体〜脚は箱で判定し、敵のしゃがみに合わせて下がります。頭部120（一撃）、胴34、脚24。
- 壁や木箱越しには当たりません（自前のグリッド光線判定）。
- 反動は「視点に残る分」と「滑らかに戻る分」に分けています。連射すると照準が上がっていくので、マウスで下へ補正する必要があります。スコープ倍率が高いほど画面上の跳ね上がりを抑えています。
- 弾痕は最大80個で、古いものから再利用します。粉塵・火花・曳光も数に上限があります。

### スコープ
FOV（視野角）を倍率に合わせて狭め、周囲を円形の黒いマスクで覆う方式です。レンズ部分は透明なので先がそのまま見えます（以前の「青いレンズで見えない」問題は起きない作り）。照準中は銃と腕を非表示にするので、標的が隠れません。倍率が上がるほどマウス感度を下げます。レンズ内だけを別カメラで描く方式は未実装です。

### リロード
銃を右へ倒して持ち上げ、左手が次の順で動きます：マガジンへ移動 → つかむ → 引き抜く → 抜いたマガジンを落とす（落下して消える） → 画面外のポーチへ → 新しいマガジンを持ってくる → 差し込む → 銃が小さく揺れる → 前方へ戻る。弾が0のときは、さらに左手が操作部（チャージングハンドル）を引いて離す動作が入ります（2.65秒、残弾ありは2.2秒）。操作部は実際に後ろへ動きます。各動作に合わせて、つかむ・抜く・差す・引く・離すの音が鳴ります。

リロード中は射撃と照準ができません。装弾数は完了時に更新します。一時停止中は進まず、ナイフ攻撃で中断した場合は弾数を変えずに元の状態へ戻ります。

### マズルフラッシュ
銃口に、白〜薄黄の中心、黄〜橙の放射状の星形、前方へ伸びる2枚の炎を約45ミリ秒表示します。毎発、大きさと回転を変えます。同時に銃と手（銃のシーン内の光）と周囲の壁（ゲーム内の光）を一瞬照らします。照準中は銃を隠すので、周囲を照らす光だけが見えます。

### 近接ナイフ
正面1.75m以内・前方の敵にだけ当たり、壁越しには当たりません。威力150（通常の敵を一撃）、攻撃後0.75秒の待ち時間。照準・ダッシュ・リロードを解除して攻撃します。銃を下げ、ナイフを持った手が右上から左下へ振り抜く簡易アニメーションがあります。

### 敵AI（12人）

- 知覚：視野（警戒前は約120°、警戒中・交戦中は約155°）、距離（最大40m、交戦中は55m）、壁と箱による遮蔽で判定します。見えている時間に応じて「発見度」が上がり、100%で発見です。姿勢が低い・動かない・遠いほど見つかりにくく、発砲直後は見つかりやすくなります。見えているときだけ「最後に見た位置」を更新します。
- 記憶と先読み：「最後に見た位置」「聞いた位置」「無線で受けた位置」を別々に持ち、最も新しい手掛かりを使います。見失ったときは、最後に見たときの移動方向へ少し先を読みます（壁の向こうへは読みません）。プレイヤーの現在位置を直接知ることはありません。
- 無線：発見した敵は1.5秒ごとに、26m以内の味方へ「見た位置」を伝えます（0.4〜0.8秒遅れて届く）。受けた味方は、その位置へ向かうか、待ち伏せに回るか、持ち場から銃を向けます。
- 役割：守備役（4人）は持ち場から動かず、見通しの長い方向（入口や通路）を順に見張ります。小銃手（3人）は手掛かりへ慎重に前進します。迂回役（3人）は見失うと別の角度（約70°以上ずれた、狙える場所）から回り込みます。突撃役（2人）は距離を詰めてきます。
- 連携：同時に詰めてくるのは最大3人で、残りは待ち伏せ（しゃがんで銃を向けて待つ）に回ります。味方同士で同じ地点に集まらないよう、目的地を少しずつずらします。仲間が倒されるのを見た敵は、すぐに身を隠します。
- 撃ち合い：発見から最初の射撃まで0.22〜0.45秒（不意の発見は少し長く）。撃ち合い中は左右に動いて的を絞らせません（守備役はしゃがんで動かない）。命中率は距離・プレイヤーの姿勢と移動・自分の移動・撃ち始めかどうかで変わり、最大85%です。味方が射線上にいるときは撃たずに横へずれます。
- 遮蔽と顔出し：撃たれた・体力が減った・弾切れのときは、「しゃがめば脅威の位置から見えない」ことを実際に確認した場所へ走ります。遮蔽物ではしゃがんで装填し、低い遮蔽（木箱）なら立ち上がって、壁の角なら一歩横へ出て撃ち返し、また隠れます（最大3回）。見えない所から撃たれたときも、まず身を隠します。
- 移動経路：手掛かりへ向かうときは、相手から見通される床を避ける経路を選びます（遮蔽物の陰を伝って進む）。
- 装填音：プレイヤーのリロード音は約9m先まで聞こえ、それを聞いた敵（守備役以外）は好機とみて一気に詰めてきます。
- 捜索・警戒解除：手掛かりの周りを4か所ほど調べ、約24秒で警戒を解いて巡回（守備役は持ち場）へ戻ります。
- 経路探索：1mグリッドのA*（斜め移動は角を削らない場合のみ）。計算は1フレーム3本まで。到達できない目的地では近くの到達可能点を探すか、あきらめて別の行動へ移ります。詰まった場合は経路を作り直し、一時的に横へ動きます。
- 弾薬：25発。撃ち切るとリロード（2.4秒、音と動作あり）。弾切れのときは、可能なら遮蔽物へ下がってから装填します。
- F3で、各敵の状態・体力・弾数・役割・発見度、経路（線、役割ごとに色分け）、最後に見た位置（赤）、聞いた位置（黄）、FPSを表示します。

#### 敵の体と動き
骨格（腰・背骨・胸・首・頭・鎖骨・上腕・前腕・手・太もも・すね・足の20本）を持つスキンメッシュ1つで1人を描いています。膝・肘・首など関節に近い部分は親子2本の骨に重みを分けているので、曲げても折れ目が出にくくなっています。

- 脚：移動速度から歩幅に合わせた周期を作り、太もも・膝・足首を動かします。腰の高さは接地側の脚から計算するので、足が床に沈んだり浮いたりしにくくなっています。走ると前傾し、歩幅が広がります。
- 上半身：歩行に合わせた腰と胸の逆ひねり、呼吸、照準の上下に合わせた背中の曲げ、視線と体の向きの差を背骨・胸・首で分担するひねり。
- 腕：両手の位置は、腕の長さから肘の角度を計算する方法（2本の骨のIK）で、右手はグリップ、左手はハンドガードに常に合わせます。リロード中は左手がマガジン → 腰のポーチ → マガジン → ハンドガードと動きます。
- 銃：平常時は銃口を下げた「ローレディ」、警戒・交戦時は肩付けに切り替わります。発砲ごとに反動で跳ね上がります。
- 被弾：撃たれた方向に応じて上半身がよろけます（頭部はより大きく）。
- 倒れ方：膝が崩れ、重力で加速しながら倒れ、床で小さく跳ねます。0.35秒後に銃が手から離れて床へ落ちます。

当たり判定は、アニメーション後の骨の位置から作るカプセル（頭・胸・腹・左右の腕・左右の脚）なので、しゃがみ・前傾・リーン・伏せでも見た目と一致します。

- リーン：腰を反対側へずらし、背骨と胸を傾けて頭を壁の外へ出します。目の位置（見る・撃つ起点）も頭に合わせて動きます。
- 伏せ：体を前へ倒し、脚を伸ばし、背中を反らせて前を見ます。銃は水平に構えます。
- 傷：脚を撃たれると痛む脚の歩幅が狭まり、体重が乗る時間が短くなり、腰が傾きます。腹を撃たれる・瀕死になると前かがみになり、呼吸が荒くなります。
- 倒れ方：撃たれた方向の反対へ倒れ、壁があれば空いている方向を選びます。床に接する高さを計算するのでめり込みません。約1.6秒で完全に止まります。

### 音（すべてWeb Audio APIで合成）
発砲、弾切れのクリック、リロード各操作、足音、着弾、敵への命中、被弾、弾が近くを通過する音、ナイフ、クリア／ゲームオーバーの短い音があります。敵の足音・銃声・リロード音は PannerNode（HRTF）で位置に合わせて鳴り、プレイヤーの位置と向きを毎フレーム反映します。壁で遮られている場合は、音量を約4割にして高音を削る簡易遮音をします。室内の残響もかけています。銃声は毎回新しい音として鳴るので、連射で前の音が途切れません。外部の音声ファイルは使っていないので、読み込み失敗は起きません。

### 見た目

壁（コンクリート・レンガ・塗装）、床、天井、木箱、金属ダクトの模様は、プログラムで描いたテクスチャ（汚れ・擦れ・剥がれ・目地・型枠穴の描き込みと凹凸）です。巾木、配管と支持金具、ドア枠、配電盤、照明器具を配置し、明るい場所と暗い場所の差、天窓からの光による影があります。

敵は、丸みのある部品と迷彩柄の服、帯とポーチの付いたベスト、ヘルメット・ゴーグル・イヤーマフ・膝パッド・ブーツで作っています。自分の銃（スコープ・レール・ハンドガード・可動する操作部とマガジン）、手袋の手（指3関節）、袖付きの腕も、角を丸めた部品と布の質感にしました。

ただし、すべてプログラムで作った形と模様で、写真のような質感や、モーションキャプチャーによる人間の動きではありません。

#### 流血表現
設定の「流血表現」で、オン（初期設定）／控えめ／オフを選べます。オンでは、命中時に弾の抜ける方向へ血しぶきが飛び、背後2.4m以内の壁や床と足元に血痕が付き、倒れた敵の下に血だまりが約4秒かけて広がります。控えめでは量と大きさを減らし、オフでは灰色の粉塵だけになります。血痕は最大60個、血だまりは最大14個で、古いものから消えます。切断などの表現はありません。

## 未実装・既知の問題

- 見た目は簡易形状の組み合わせで、写実的な3Dモデルや写真素材のテクスチャは使っていません。次の段階で、利用条件を確認した既製モデル（glTF）への置き換えを検討します。
- 敵の体は、プログラムで作った形と、計算で作った動き（手続き的アニメーション）です。モーションキャプチャーのような自然さはなく、方向転換時の足の踏み替えは簡略です。倒れ方は物理演算（ラグドール）ではありません。壁のない方向へ倒れるようにしていますが、四方が狭い場所では体の一部が壁や木箱に重なることがあります。
- うめき声と足音はすべて計算で作った合成音で、人や実際の足音の録音ではありません。以前より自然になりましたが、録音された音には及びません。
- 参考画像のような写実的な見た目には、専門のアーティストが作った3Dモデルと質感が必要です。今回は色調・光・質感で雰囲気を近づけた段階です。
- 敵が落とした銃は飾りで、拾えません。
- 武器はアサルトライフル・ハンドガン・ショットガン・手りゅう弾です。敵は手りゅう弾を投げてきません。
- マップの切り替えはタイトル画面でのみできます（選ぶとページを読み込み直します）。
- ドアと「調べる」（F）は未実装です。
- 指は関節がありますが、マガジンをつかむときの指の形は簡略です。リロード中、角度によっては手とマガジンがわずかに離れて見えることがあります。
- ナイフは簡易モデルと単純な振り抜きだけです。
- 匍匐中の体の当たり判定は円柱のままで、体の長さ（前後）を反映していません。
- 遮音は音が鳴り始めた瞬間に1回だけ判定します。長い音の途中で壁の陰に入っても変わりません。
- 敵は立ったまま通れる場所だけを移動します（ダクト下や壁の隙間は使いません）。
- 敵の発見判定は線が通るかどうかで、暗さは考慮していません。
- 照準を解除する動作（リロードなど）の後も右クリックを押し続けていれば、終わり次第また照準に入ります。
- マウスボタンのキー設定は未対応です。
- BGMはありません（仕様どおり）。

## 自動テストの実行方法（開発者向け）

ゲーム本体には不要です。Python と Playwright がある環境で、`index.html?manual&autotest` を開き、`tests/auto-tests.js` の内容をページ内で実行すると、結果が PASS／FAIL の一覧で返ります。`?autotest` はマウス固定なしでゲームを開始する開発用の指定、`?manual` は自動描画を止めてテストからフレームを進めるための指定です。
